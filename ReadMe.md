### Core Idea
Python library concept for assessing the alignment between resumes and job descriptions.

Will be using NLP and semantic similarity to analyze resumes and job postings, identify relevant technical and soft skills, and highlight potential skill gaps.

##### Planned Features ( As of now )
- Resume and job description analysis
- Semantic similarity-based matching
- Technical and soft skill extraction
- Skill-gap identification
- Candidate–position alignment analysis
- Exportable visual reports ( maybe challenging)

The primary target audience: HR professionals and recruiters, and hopefully more.
